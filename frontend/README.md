# Ghost TV Frontend 🎬

The client-side web application for **Ghost TV**, built with **React 19**, **TypeScript**, and **Vite**.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## 🛠 Tech Stack & Features

- **React 19 & TypeScript:** Modern, type-safe functional components.
- **Vite 8:** Lightning-fast HMR and optimized production bundling.
- **React Router v7:** Client-side SPA navigation with `vercel.json` rewrite support.
- **Custom Design System:** Responsive dark UI with glassmorphism effects, hover interactions, and touch/drag scroll rows (`useDraggableScroll`).
- **LocalStorage History:** Automated episode watch tracking (`src/services/history.ts`).
